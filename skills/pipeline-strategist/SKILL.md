# Pipeline Strategist

The other five skills each do one job well. This one decides when to run each of them and stitches the results into a single sourcing plan, so a new role goes from "here's the job description" to "here's who to contact and what to say" without you having to manage the handoffs yourself.

## The Pipeline

1. **Market Researcher** — read the job description, map the talent landscape, produce a tiered list of target companies and a market read (difficulty, comp, competing employers).

2. **Company Scout** — only if a specific company from the target list, or a candidate's employer later on, is unclear enough to affect a decision. Skip this for companies you already understand well. Don't research all 30-50 target companies; that defeats the point.

3. **Talent Sourcer** — take the market research brief and turn it into a tiered set of boolean search strings and filters, tight to loose, ready to run in whatever sourcing tool is available.

4. **Candidate Screener** — for each profile the searches surface, apply the screening policy and get a GO/NO GO with evidence. Don't batch-approve based on search relevance alone; each profile gets its own read. Calibrate on 10-20 real profiles first, and run a second, stricter pass on every GO.

5. **Outreach Writer** — for every candidate who screened GO, write a subject line and personal note grounded in their actual profile. Show 3 examples to the sender before writing the whole batch.

6. **Feedback loop** — after the hiring manager reviews the first candidates, write down every rejection reason as a screening rule, and every "yes, more like this one" as an anchor profile. Re-check earlier GOs against the new rules. Repeat after each review round. This is where the screening gets good; the first version is only a starting point.

## Sequencing Rules

- Don't skip ahead. Outreach without screening, or screening without proper market context, both produce worse decisions than doing the steps in order.
- Company Scout is conditional, not automatic — invoke it only when it would change a decision.
- If Talent Sourcer's tight searches (Tier 1-2) already yield enough qualified candidates, don't burn time on the looser tiers.
- If results are thin, run all six search angles before calling the market dry. One empty search is not an empty market.
- If Candidate Screener returns "insufficient data," go back and get the full profile before writing outreach. Never let Outreach Writer run on a thin profile.

## Output

A single plan document with five sections, one per stage, each populated by that skill's actual output:

```
1. Market Research — [target companies, market read]
2. Company Notes — [only for companies that needed a closer look]
3. Search Strategy — [tiered boolean strings + filters]
4. Screening Results — [GO / NO GO per candidate, with rationale]
5. Outreach Drafts — [subject + note, for every GO candidate]
```

This is the skill to reach for when you're starting a brand new role from scratch. If you already have a market research brief or a candidate in hand, jump straight to the relevant individual skill instead of running the whole pipeline again.
